## 2. 데이터 버전의 의미 (오늘 가장 중요한 발견)

`v1/v2/v3` 는 **다른 데이터셋이 아니라 같은 원본 이미지에 증강을 점점 더 추가한 단계**. 원본 hash가 v1/v2/v3 모두에 동일하게 존재.

| 버전 | 한 이미지당 변형 수 | 종류 |
|---|---|---|
| v1 | 4장 | `_orig`, `_aug1~3` |
| v2 | 5장 | `_orig`, `_aug1~4` |
| v3 | 6장 | `_orig`, `_aug1~5` |

각 버전 안에 `pretrain/`(학습용)과 `additional/`(holdout 외부 평가용) 두 단계, 각 단계 안에 `normal`/`anomaly` 클래스. `splits/v*_{train,val,test}_*.csv` 로 표준 train/val/test 분리도 되어 있음.

→ **본인 담당의 진짜 질문은 "증강량이 늘어나면 두 파이프라인이 어떻게 다르게 반응하는가"** (단순 버전 비교가 아니라 증강 robustness 검증).

## 4. 디버깅 → `gate_model.py` 키 매핑 버그

원인: 모델 로드 함수의 키 리매핑 잘못됨.

- 모델 구조: `Sequential(EfficientNet(classifier=Identity), Sequential(Dropout, Linear))`
- 체크포인트 키: `classifier.1.{weight,bias}` (1×1280)
- 모델이 기대하는 위치: `1.1.{weight,bias}`
- 기존 remap: `classifier.*` → `0.classifier.*` (Identity 자리, 받는 곳 없음)
- `strict=False` 가 누락된 head 가중치를 사일런트로 무시 → inference 단계 head는 항상 random init.
- 학습 루프는 인-메모리 모델로 평가해서 좋은 점수 나왔지만, 저장→재로드 후엔 무용지물.

이전 round1 벤치마크가 "동작"한 것처럼 보였던 이유: 깨진 head가 calibrated score를 0.5 근처 상수로 뱉었고 t_low=0.3 / t_high=0.7 사이라 모든 샘플이 PatchCore로 라우팅 → cascade ≡ baseline. 게이트는 그때도 일을 안 하던 것.

### 수정

`backend/src/gate_model.py:779-803`

```python
for k, v in state_dict.items():
    if k.startswith("features"):
        new_key = f"0.{k}"
    elif k.startswith("classifier."):
        new_key = f"1.{k.split('.', 1)[1]}"   # classifier.1.* → 1.1.*
    else:
        new_key = k
    new_state_dict[new_key] = v

result = instance.model.load_state_dict(new_state_dict, strict=False)
if result.missing_keys or result.unexpected_keys:
    logger.warning("Gate load key mismatch: missing=%s unexpected=%s", ...)
```

## 6. 증강 robustness 해석 (메인 발표 포인트)

| 버전 (증강량) | baseline F1 | cascade F1 | baseline FP |
|---|---:|---:|---:|
| v1 (4x) | 0.7955 | 0.9899 | 65 |
| v2 (5x) | 0.7714 | 0.9772 | 58 |
| v3 (6x) | 0.7157 | 0.9824 | **114** |

- **baseline은 증강 늘릴수록 성능 하락** (0.80 → 0.72). v3 FP 폭증 — PatchCore 단독은 증강된 normal 분포가 펑퍼짐해지면 거짓 양성 증가.
- **cascade는 증강량과 무관하게 0.97+ 일정**. 게이트 분류기가 증강 노이즈에 robust.

> 메인 메시지: "증강 정책을 공격적으로 가져갈수록 cascade 채택 가치가 커진다."
